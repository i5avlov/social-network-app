# Social Network App
ASP.NET Core Web App

## Overview 
A basic Facebook-like social network where 
- a user registers and creates a profile 
- creates posts comprised of text and images 
- uploads images 
- finds other users and explores their profiles 
    * including their posts 
- sends invitations for friendship and after the other user's acceptance 
    * sends and receives messages to and from them 
    * can add comments to and like their posts
